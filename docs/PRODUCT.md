# PRODUCT.md — 工惠新锋开发版 PRD 基线

状态：DRAFT  
来源：客户《“工惠新锋”小程序产品需求方案 V1.0》

## 1. 产品定位
面向外卖骑手、快递员等新就业形态劳动者，通过轻量化、游戏化、服务化方式完成思想引领和工会服务触达。

核心口号：抢的是精神力量，得的是生活实惠，当的是骑士先锋。

## 2. 核心业务闭环
微信登录 → 身份认证 → 查看抢单时段 → 抢单 → 1 分钟视频/语音学习 → 1~3 题答题 → 打卡 → 获得金币/红包 → 等级成长 → 商城兑换 → 高等级用户参与工会新锋联盟。

## 3. 角色
### U1 骑手用户
- 微信登录、身份认证
- 抢单、学习、答题、打卡
- 获取/使用金币
- 获取/使用或提现红包（真实方案待确认）
- 商城兑换
- 等级、徽章、联盟

### U2 工会管理员
- 用户及身份审核
- 内容、题库、抢单活动配置
- 金币/红包规则
- 商城、订单、公告
- 数据看板

### U3 商家/服务方
- 被授权后管理商品/服务
- 核销兑换码
- 查看必要的订单/结算信息

### U4 系统管理员
- 全部后台权限
- 系统配置、数据维护、运维

## 4. 产品原则
- 轻量化：学习内容 ≤ 1 分钟，核心动作尽量 ≤ 3 步。
- 游戏化：抢单、金币、红包、等级、徽章。
- 真实惠：金币用于真实商品/服务；现金奖励方案须满足微信与财务合规。
- 精准化：主要面向完成新就业形态劳动者身份认证的用户。
- 安全合规：先审后发、用户数据保护、资金可审计、行为风控。

## 5. MVP 范围
### 用户端
1. 微信登录与身份认证
2. 首页/抢单
3. 学习内容播放
4. 答题与结果
5. 打卡
6. 金币账户与明细
7. 商城、兑换、核销码
8. 个人中心、等级、徽章
9. 消息/公告

### 管理后台
1. 用户与认证审核
2. 内容管理
3. 题库
4. 抢单活动
5. 金币与红包管理
6. 商城/订单/商家
7. 公告消息
8. 数据看板

## 6. 非功能目标
- 小程序常规页面加载目标 ≤ 2 秒。
- 抢单接口目标响应 ≤ 500ms。
- 单场预估瞬时并发 ≤ 200 人。
- 用户敏感数据加密/脱敏。
- 关键接口防刷、防注入、防重放。
- 数据看板统计延迟目标 ≤ 10 分钟。
- 兼容微信小程序最新基础库及前两个版本，适配主流 iOS/Android 分辨率。

## 7. 第三方能力
- 微信登录
- 微信支付（若启用金币+现金）
- 微信消息能力
- 对象存储（COS/OSS 二选一，待部署阶段确定）
- 微信原生 video
- 短信、地图签到均为可选项

## 8. 推荐技术基线（待 D-TECH-001 确认）
- 小程序：微信原生 + TypeScript + TDesign Miniprogram
- 后台：Vue 3 + Vben Admin
- API：NestJS
- ORM：Prisma
- 数据库：MySQL
- 缓存/抢单原子控制：Redis

## 9. 开发策略
先完成 Mock UI 原型，再完成数据库/API 与核心闭环；真实微信支付、红包、公众号内容接入放在核心功能稳定后实施。

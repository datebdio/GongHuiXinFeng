# PAGE_SPEC.md

## 用户端页面

### P-U01 启动/登录
- 微信登录入口
- 用户协议、隐私政策勾选
- 首次登录后进入 P-U02

### P-U02 身份认证
- 身份：外卖骑手 / 快递员
- 上传三选一证明材料
- 提交后展示审核中状态

### P-U03 首页 / 抢单
核心模块：
- 用户条：头像、昵称、等级、金币余额
- 今日抢单：时段、倒计时、剩余名额、按钮状态
- 每日学习卡片
- 政策速递
- 排行榜
- 活动通知

抢单按钮状态：`WAITING / OPEN / SOLD_OUT / FINISHED / CLAIMED`

### P-U04 学习中心
- 内容分类
- 文章/学习内容列表
- 标题、金币奖励、已领取/未领取
- 分类与已学筛选

### P-U05 学习详情
- 视频/语音/文章内容
- 进度
- 抢单任务剩余时间（若来自抢单）
- 播放完成后进入答题

### P-U06 答题
- 1~3 道单选题
- 剩余时间
- 中途退出后允许恢复

### P-U07 答题结果
- 正确题数/正确率
- 金币奖励
- 红包结果（Mock/真实由 Provider 决定）
- “打卡并领取”主按钮

### P-U08 金币商城
- 当前金币余额
- 商品分类
- 商品卡：图、名称、定价、库存/状态

### P-U09 商品详情
- 商品图、介绍、使用规则
- 纯金币或金币+现金价格
- 库存
- 兑换按钮

### P-U10 兑换确认
- 商品信息
- 金币/现金确认
- 使用规则确认

### P-U11 兑换成功
- 唯一兑换码/二维码
- 有效期
- 使用说明

### P-U12 个人中心
- 头像、昵称、新锋编号、身份、认证状态
- 当前等级/徽章
- 金币、红包入口
- 打卡、联盟、消息、设置

### P-U13 等级徽章
- 当前等级
- 累计获得金币
- 等级门槛与权益
- 徽章墙

### P-U14 金币明细
- 当前余额
- 获得/冻结/消耗/过期/人工调整流水

### P-U15 红包明细
- 红包金额/余额（最终形态待 D-REDPACK-001）
- 来源、状态、时间

### P-U16 打卡日历
- 连续打卡天数
- 月历
- 历史学习记录

### P-U17 新锋联盟
- 资格说明
- 申请/邀请状态
- 成员权益
- 联盟任务入口

### P-U18 消息中心
- 系统通知
- 活动通知
- 审核结果
- 兑换相关通知

### P-U19 设置与帮助
- 联系工会
- 意见反馈
- 隐私政策
- 用户协议

## 管理后台页面

### P-A01 登录
管理员登录。

### P-A02 数据看板
注册/认证、DAU/MAU、抢单、学习、答题、金币、红包、商城、等级等指标。

### P-A03 用户管理
搜索、筛选、查看认证状态/等级/金币/活跃度、黑名单。

### P-A04 认证审核
材料查看、通过、驳回、审核日志。

### P-A05 内容管理
视频/语音/文章内容列表，分类、审核、上下线。

### P-A06 内容编辑
上传 mp4/mp3，配置标题、分类、封面、奖励、状态；公众号文章来源按 D-CONTENT-001。

### P-A07 题库管理
题目列表、分类、难度、答题统计。

### P-A08 题目录入
单选题、选项、正确答案、难度、分类。

### P-A09 抢单活动配置
时段、名额、每日次数、绑定学习内容、奖励规则、活动状态。

### P-A10 金币规则
行为奖励、连续打卡、分享奖励、有效期、人工调整入口。

### P-A11 红包管理
金额池、单场预算、金额范围、概率/规则、发放记录、Mock/真实 Provider 状态。

### P-A12 商城商品管理
商品、分类、库存、价格类型、有效期、上下架。

### P-A13 订单管理
兑换记录、支付状态（如有）、核销状态、发货/履约状态。

### P-A14 商家管理/核销
商家、核销员、结算记录；扫码或输入码核销。

### P-A15 公告消息
政策速递、活动、系统公告及消息模板。

## Mock UI 第一批
优先只做以下页面形成可演示闭环：
`P-U01 → P-U02 → P-U03 → P-U05 → P-U06 → P-U07 → P-U08 → P-U09 → P-U12`

Mock 场景至少包含：
1. 抢单未开始倒计时；
2. 抢单成功并剩余 3 分钟；
3. 完成 1 分钟学习；
4. 完成 3 道题；
5. 获得金币并随机命中/未命中红包；
6. 商城查看商品；
7. 个人中心查看等级和余额。
